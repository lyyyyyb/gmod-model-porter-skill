# 故障诊断表

## 使用规则

先复现并保存截图，再只改变一个变量。相同路线最多三次；第三次仍失败就更换路线并恢复到最后一个已验收基线。

| 现象 | 优先检查 | 常见原因 | 修复方向 |
| --- | --- | --- | --- |
| PM 全程 T 字 | PM QC 动画引用、ValveBiped 骨名 | 没有 `f_anm.mdl`、骨架不兼容 | 修正骨映射和 PM 动画引用 |
| NPC 全部 T 字 | NPC Lua 模型路径、NPC QC 二进制动画引用 | NPC 直接使用 PM 模型 | 编译专用 NPC 模型并包含四套 female Citizen 动画 |
| NPC 旧实例仍 T 字 | 游戏缓存、地图旧实体 | 文件已换但实体仍引用旧模型实例 | 完全重启游戏，删除旧 NPC 后重新生成 |
| 角色比 Alyx 高一个头 | 人体测量点、辅助网格 | 把尾巴/耳朵/帽子算入高度，或单位换算错误 | 以脚底到真实头顶缩放并编译复测 |
| 肩或手臂卷曲 | 上臂骨方向、Proportion 动画、权重 | 本地轴错误或裁切跨关节 | 对照参考骨架，分别排查骨与权重 |
| C-Arms 手指细长 | 角色原手比例、手指局部网格 | 只套标准骨但未适配角色网格 | 保留骨，逐节调整角色手指几何 |
| C-Arms 手指撕裂 | 手指根部权重 | 整体自动重算权重破坏支撑分布 | 回退已验证权重，只局部修网格/权重 |
| C-Arms 穿模 | 网格来源、裁切高度、袖子 | 直接使用参考 addon 手或裁切过高 | 使用角色自身手臂，参考方法而非成品 |
| C-Arms 挡住视野 | 外套袖宽、自动手模选择 | 第一人称使用厚外套袖 | 外套状态默认裸手，JK 状态用 JK 袖 |
| 外套脱下没有 JK | 身体组互斥关系 | JK 与外套被做成同一组或内层被删除 | 独立 JK/外套层并测试组合 |
| 红圈位置露出残片 | 网格分割边界 | 身体组关闭时仍有同对象面片 | 回到 Blender 按顶点/面精确拆分 |
| 衣服可脱但不应可脱 | Lua/QC 暴露非法组合 | 机械保留原始对象开关 | 只保留用户允许的穿衣组合 |
| 尾巴横着或全部向下 | Rest Pose、骨本地轴、Unity 默认动画 | 没应用 Unity tail control 默认姿势 | 从 Unity 动画重建默认姿势后再导出 |
| 单尾选项出现九条 | Bodygroup 网格内容 | 九尾网格被复用到所有尾巴组 | 每个单尾选项单独导出一条尾巴 |
| 九尾不分开 | 骨链被合并或权重塌到一条链 | 辅助骨重名/父链丢失 | 保留九条独立链和各自顶点组 |
| 尾巴两种颜色 | 重叠网格、重复材质槽、法线/双面 | 两套尾巴同时显示，不一定是贴图色差 | 隐藏单个网格逐一验证，先消除重叠 |
| 尾巴左右明暗不同 | 法线、切线、镜像、`$nocull` | 镜像法线或背面渲染 | 重算法线并检查 VMT 双面设置 |
| 黑灰衣服变纯黑 | VTF 色彩、Phong、颜色乘数、法线标记 | 光照参数过强或贴图格式错误 | 分项关闭材质参数，验证原图和 VTF 回读 |
| 背面透明 | VMT 与法线 | 未设置 `$nocull 1` 或法线翻转 | 对需要的材质开启双面并修法线 |
| 透明边缘发黑 | Alpha 模式、预乘、Mipmap | Shader/格式不匹配 | 区分 `$translucent` 和 `$alphatest` 并重建 VTF |
| 光影像自发光 | `$selfillum`、Phong、VertexLit 参数 | 把 VRChat Shader 效果误映射 | 回到标准 VertexLitGeneric 逐项增加功能 |
| 头发/裙摆几乎不动 | Jiggle 根选择和刚度 | 只给末端骨或参数过硬 | 按 Unity 链选择根，分部位调参数 |
| 动骨爆甩 | 骨轴、链父子、参数 | 父链断裂或弹性过大 | 先修骨链，再降低振幅/增加阻尼 |
| 胸部不该动 | QC 仍有胸部 Jiggle | 只调低参数没有删除 | 删除胸部 Jiggle 块并重新编译 |
| 头顶打不中 | Head Hitbox 上界 | 按骨头位置而非加权网格制作 | 计算头部加权网格局部边界 |
| 脚打不中 | Foot Hitbox 缺失或太短 | 只覆盖小腿 | 单独添加左右脚 Hitbox 并覆盖鞋底脚尖 |
| Hitbox 包住尾巴/头发 | 审计对象未排除装饰 | 直接使用整体包围盒 | 排除装饰网格，只使用人体加权区域 |
| 活着不眨眼 | Flex、QC 映射 | 缺 `blink` Shape/Flex Controller | 保留 Shape Key 并映射 `%blink` |
| 死亡不闭眼 | Ragdoll Flex 状态 | 自动 blink 不会固定在尸体 | Ragdoll 创建时客户端设置 `blink=1` |
| 玩家死亡闭眼、NPC 不闭眼 | 模型路径过滤 | 只匹配 `models/player/...` | 同时匹配专用 `models/npc/...` |
| 独立 Ragdoll 不闭眼 | 只监听客户端死亡 Hook | 菜单 Ragdoll 是联网 `prop_ragdoll` | 同时监听联网实体创建并只筛 Ragdoll |
| 宠物绑在人物上 | 原版行为判断错误 | Unity 中其实是独立跟随对象 | 能做独立实体才保留，否则删除 |
| 模型看似更新但游戏未变 | Addon 重复、缓存、只覆盖单文件 | 旧 addon 后加载或 GMod 未重启 | 搜索重复路径，完整替换并重启 |
| StudioMDL 成功但游戏报错 | 五件套或材质缺失 | 只复制 `.mdl` | 复制全部模型伴随文件和材质 |
| Workshop 版与本地不同 | GMA 内容或旧上传 | 未反解验证或上传错文件 | 解包 GMA 哈希比较并记录 GMA SHA256 |

## 三次失败后的换路线示例

- 自动权重三次仍撕裂：回退已验证权重，改为局部手工调整。
- 尾巴颜色三次仍异常：隐藏/删除可疑重复网格，从 Unity 单个开关重新导出，不再调材质参数。
- Blender GUI/MCP 三次无法稳定保存：切换 Blender 后台 Python，输出编号 Blend 和 JSON 报告。
- 热替换三次仍显示旧模型：停止热更新，完全退出 GMod，备份后完整替换 addon。
