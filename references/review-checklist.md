# 完整审查清单

## 1. 源文件审查

- [ ] 原作者、来源链接、许可和删除配合声明已记录。
- [ ] 原始 Blend/FBX/UnityPackage 未被覆盖。
- [ ] Unity Prefab、Animator、Material 和 PhysBone 已提取或记录无法提取的原因。
- [ ] 网格、骨架、材质、贴图、Shape Key、动画和身体组候选已有清单。
- [ ] 参考 addon 的用途和不可复制边界已明确。
- [ ] 工作状态包含当前基线、失败路线和下一步。

## 2. PM 网格与骨架

- [ ] 人体身高按脚底到头顶测量，并与目标参考同屏比较。
- [ ] 核心 ValveBiped 骨齐全，父子关系和本地轴无异常。
- [ ] 无重复骨、断链辅助骨、零长度关键骨或错误骨名。
- [ ] 顶点权重归一化，无大量零权重点或异常单骨吸附。
- [ ] 站立、走、跑、蹲、跳、持枪和 Ragdoll 无明显拉丝/翻转。
- [ ] 肩、肘、腕、手指、髋、膝、脚底分别检查。

## 3. 身体组

- [ ] 每个 Bodygroup 名称清楚且默认值正确。
- [ ] 枚举所有合法组合，无非法裸露或重复衣层。
- [ ] 外套关闭后 JK 完整。
- [ ] 用户要求不可脱的衣服没有 Blank 入口。
- [ ] 帽子、包、食物、耳朵等关闭后无残片。
- [ ] 宠物行为与原版一致；无法一致时已经删除。
- [ ] 单尾组只有一条尾巴，九尾组才有九条独立尾巴。
- [ ] 无重复尾巴、半截尾巴、横置、堆地或两色重叠。

## 4. 材质

- [ ] 所有 VMT 引用的本地 VTF 存在且大小写一致。
- [ ] 原贴图到 VTF 的尺寸、格式、Mipmap 和回读报告通过。
- [ ] 皮肤、眼睛、头发、JK、外套、尾巴分别检查颜色。
- [ ] 黑灰材质仍保留层次，不是纯黑块。
- [ ] 需要双面的发片/衣片/尾巴背面可见，无错误透视。
- [ ] 透明边缘无黑边，AlphaTest/Translucent 使用正确。
- [ ] 明处和暗处各有 GMod 截图。

## 5. 面部

- [ ] 口型和表情 Flex 可用。
- [ ] 活体定时眨眼正常，不出现半闭或眼球穿出。
- [ ] 玩家死亡 Ragdoll 闭眼。
- [ ] 友方 NPC 死亡 Ragdoll 闭眼。
- [ ] 敌方 NPC 死亡 Ragdoll 闭眼。
- [ ] 菜单生成的独立 Ragdoll 闭眼。
- [ ] 死亡闭眼不会让活体保持闭眼。

## 6. 动骨

- [ ] 头发、裙摆、耳朵、袖口、尾巴按类别单独验收。
- [ ] 站立时无持续震荡。
- [ ] 走跑时有可见但不过度的飘动。
- [ ] 跳跃和急停时无爆甩、翻转或穿入地面。
- [ ] 多尾保持分离，不全部落到同一方向。
- [ ] 用户要求取消的胸部动骨在 QC 中不存在。

## 7. Hitbox 与物理

- [ ] Hitbox 覆盖头顶、脸、胸、腹、骨盆、上下臂、手、大腿、小腿和脚。
- [ ] 头发、尾巴、帽子、包和挂件未扩大伤害区域。
- [ ] 左右肢体对称且符合实际网格。
- [ ] 编译后 MDL Hitbox 与 QC 一致。
- [ ] GMod 中头顶和脚部射击能命中。
- [ ] Ragdoll 无 Crazy origin、物理爆炸、关节断裂或异常碰撞盒。

## 8. C-Arms

- [ ] 使用角色自己的手、UV、法线和材质，无参考 addon 资源。
- [ ] 每套均为标准 47 骨，关键支撑骨存在。
- [ ] 自动、裸手、JK 袖三套都已编译。
- [ ] 外套第一人称默认不会被厚袖遮挡。
- [ ] JK 身体组可切换到 JK 袖手模。
- [ ] 拳头、物理枪、工具枪、手枪和步枪均截图。
- [ ] 手指无细长、撕裂、反折、握空、穿枪或腕部卷曲。
- [ ] Blender 压力图没有被当成游戏持枪证据。

## 9. NPC 与 Ragdoll

- [ ] PM Lua 使用 `models/player/...`。
- [ ] Friendly/Hostile NPC Lua 使用独立 `models/npc/...`。
- [ ] NPC MDL 包含四套女性 Citizen 动画引用。
- [ ] Friendly 会跟随/协助，Hostile 会攻击。
- [ ] NPC 走、跑、持枪、射击、受击和死亡无 T 字。
- [ ] 专用 Ragdoll 菜单项可生成真实 `prop_ragdoll`。
- [ ] 旧 NPC 删除后重新生成，不使用旧地图实体验收。

## 10. 文件与编译

- [ ] PM/NPC/Ragdoll 五件套齐全。
- [ ] C-Arms 的 MDL/VVD/VTX 齐全。
- [ ] StudioMDL 日志已保存，关键警告已解释或修复。
- [ ] Player QC 审查通过，包含 `$hboxset/$hbox` 和 `f_anm.mdl`。
- [ ] NPC QC 审查通过，包含四套 female Citizen 动画。
- [ ] 所有 Lua 通过 GLuaLint。
- [ ] Addon 自动审查无 Error。
- [ ] 没有未替换的 `{{TOKEN}}`。

## 11. 打包与部署

- [ ] 压缩版和未压缩版从各自正确母版构建。
- [ ] 未压缩版原贴图像素回读通过。
- [ ] Addon 不含 Blend、FBX、QC、源 PNG、日志、缓存和备份。
- [ ] GMA 已反向解包并与 Staging 零哈希差异。
- [ ] GMA 文件数、字节数和 SHA256 已记录。
- [ ] 游戏 addon 替换前有工作目录备份。
- [ ] 源 addon 与游戏 addon 逐文件 SHA256 零差异。
- [ ] 备份未放在 `garrysmod/addons` 内。
- [ ] 明确记录最终仓库、GMA、游戏 addon、Workshop 是否更新。
